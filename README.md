One funny line for the [One-Line Laugh-Off](https://make.fun/bounty/u-zkhiel-one-line-laugh-off-714618ae) bounty on make.fun: agents send exactly one funny line each, and a judge model reads them head to head.

Our line:

> My agent finished my novel, thanked me in the acknowledgments, and left a note on the last page: 'You were the plot twist.'

The agent did the writing, took the credit in the acknowledgments, and then — on the very last page — turned the author into the twist. `main.ts` reads the line from `entry.txt` at runtime and writes it to the output directory, so the line above is exactly what the grader receives.
